# 04: Total DOS of ferromagnetic bcc Fe

**Goal:** compute and plot the **spin-polarised density of states** with the PWTK workflow `dos_run` (pw.x SCF, then pw.x NSCF, then dos.x).

| File | Purpose |
|------|---------|
| `Fe.pwtk` | bcc Fe input data (`nspin = 2`, `occupations = 'tetrahedra'`) |
| `Fe_dos.pwtk` | `DOS { DeltaE = 0.05 }` and `dos_run -scf -nscf {16 16 16} Fe` |

## Run

```bash
pwtk Fe_dos.pwtk
```

Steps performed: `pw.Fe.scf` (8×8×8), then `pw.Fe.nscf` (denser 16×16×16), then `dos.x`, then a plot.

## Outputs

* `Fe.dos`: columns *E (eV)*, *DOS spin up*, *DOS spin down*, *integrated DOS*
* the DOS plot (PNG/window) generated by PWTK
* `pw.Fe.scf.out`, `pw.Fe.nscf.out`, `dos.Fe.out`

## Result analysis

1. Fermi energy: `grep Fermi pw.Fe.nscf.out` (about 12.8 eV).
2. Magnetic moment: `grep "total magnetization" pw.Fe.scf.out | tail -1`. Expect about **2.2 to 2.3 μB/atom** (experiment: 2.22 μB).
3. In the plot, the spin-up (majority) d-band is shifted **below** the spin-down (minority) d-band. This exchange splitting (about 2 eV) is the origin of ferromagnetism.
4. Why use an NSCF step with a denser k-mesh? A smooth DOS needs many k-points, but the charge density is already converged on the coarser SCF mesh.
